      Cómo calcula

      Si un partido tiene cuotas, la web usa la probabilidad que implican, sin el margen de las casas. Si además escribes los goles de los equipos en Datos del partido, verás el modelo como referencia. La tabla de marcadores del pleno sale del modelo y, sin goles, es solo orientativa.

      ataque = (GF + μ·peso) / (PJ + peso) / μ × (1 + ajuste) defensa = (GC + μ·peso) / (PJ + peso) / μ × (1 − ajuste) valor = (valor XI local / valor XI visitante)^β λ local = base × ataque_local × defensa_visit × campo × valor λ visitante = base × ataque_visit × defensa_local ÷ campo ÷ valor P(k goles) = e^(−λ) · λ^k / k! Dixon-Coles: 0-0 ×(1 − λl·λv·ρ) 1-1 ×(1 − ρ) 0-1 ×(1 + λl·ρ) 1-0 ×(1 + λv·ρ) Casas: p = (1/cuota)^k, con k tal que 1, X y 2 sumen 1 Final = (1 − peso)·modelo + peso·casas

      Dixon-Coles corrige los marcadores bajos, donde el Poisson simple se equivoca más: con ρ negativo suben el 0-0 y el 1-1, y con ello la X. Si un partido tiene cuotas, la web quita el margen con el método de potencia y usa esa probabilidad; el modelo queda como referencia. En 6.440 partidos de LaLiga, Segunda y Premier desde 2021, ese método redujo un poco el error frente al reparto proporcional (log-loss 0,9883 frente a 0,9894), y las cuotas de última hora lo redujeron algo más (0,9855). En otra prueba con 90 partidos europeos, las casas acertaron el favorito el 62% de las veces y el modelo el 53%. Puedes cambiar el peso de las cuotas en los parámetros.
